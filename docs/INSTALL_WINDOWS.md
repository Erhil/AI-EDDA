# Установка в Windows

Откройте PowerShell в папке проекта и выполните `./setup.ps1`. При первом запуске задайте пароль владельца. Повторная установка сохранит его.

По умолчанию установка выбирает CUDA. Для CPU выполните `./setup.ps1 -Device cpu`. Чтобы скачать модель сразу, добавьте `-DownloadModel`. Если готового интерфейса нет, установите Node.js 24 и npm: они нужны только для сборки. Для повторной сборки добавьте `-RebuildFrontend`.

Запустите сервер командой `./start.ps1`. По умолчанию он доступен только на этом компьютере. Остановите его через Ctrl+C. Папки данных можно выбрать параметрами `-ProjectRoot` и `-ConfigRoot` в обеих командах.

Для доступа по локальной сети укажите имена и IP адреса сертификата при установке: `./setup.ps1 -TlsName localhost,127.0.0.1,192.168.1.10`. Используйте реальный адрес компьютера. Сертификат не заменяется автоматически. Вручную установите доверие к выданному CA на каждом клиенте и разрешите выбранный порт в брандмауэре. Затем запустите `./start.ps1 -ServerHost 0.0.0.0 -Port 8000` и откройте HTTPS по имени или адресу из сертификата. Перед установкой доверия проверьте отпечаток CA, который выводит команда.
